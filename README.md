# خيط (Khayt)

تطبيق أندرويد يرسم على خريطة نافذة عائمة كل ما يتصل به هاتفك: من أي تطبيق، وإلى أين، وهل هو موقع عادي أم إعلانات وتتبّع.
كل المعالجة داخل الهاتف، ولا يُرسل شيء إلى أي خادم.

> ملاحظة صريحة: هذا الكود كُتب دون إمكانية بنائه أو تشغيله على جهاز حقيقي. توقّع أن تصلح بعض أخطاء البناء الصغيرة عند أول تشغيل.

## الفكرة

- **رصد:** خدمة VPN محلية توجّه عنوان DNS وهميًا (`10.7.0.2`) إلى نفق التطبيق. بقية حركة الإنترنت لا تمر بالنفق ولا تتأثر. كل استعلام DNS يُنسب إلى تطبيقه عبر `getConnectionOwnerUid`.
- **المواقع:** يُحوَّل عنوان IP الذي يرجع به الخادم إلى موقع تقريبي بقاعدة GeoLite2 محليًا.
- **المتتبّعات:** مطابقة النطاق (ونطاقاته الفرعية) بقائمة `assets/trackers.txt`.
- **الخريطة:** صفحة `assets/map.html` داخل WebView عائم. سُمك الخط يزيد بكثرة الاتصالات.
- **قطع الخط:** اضغط خطًا ثم «اقطع». يردّ التطبيق على ذلك النطاق بـ NXDOMAIN فلا يستطيع أي تطبيق الوصول إليه.
- **الريبلاي:** زر «أعد آخر 8 ساعات» يعيد تشغيل السجل في 20 ثانية.

## التشغيل

1. افتح المجلد في Android Studio (إصدار حديث) ودعه يزامن Gradle.
2. نزّل `GeoLite2-City.mmdb` مجانًا من MaxMind (يحتاج حسابًا مجانيًا) وضعه في `app/src/main/assets/`.
3. شغّل التطبيق على هاتف بأندرويد 10 أو أحدث، ثم اتبع الأزرار الثلاثة في الشاشة الرئيسية.
4. ليظهر موقعك الحقيقي اسمح بالموقع التقريبي. وإلا فعدّل القيم الافتراضية في `Config.kt`.

## حدود يجب معرفتها

- يرى التطبيق أسماء النطاقات فقط، لا محتوى ما تقرؤه.
- التطبيقات التي تستخدم DNS مشفّرًا خاصًا بها (DoH) لن تظهر، وكذلك Private DNS في وضع صارم. عطّل Private DNS أو اجعله تلقائيًا.
- الموقع المعروض هو موقع الخادم أو شبكة التوصيل (CDN) وليس مقر الشركة.
- يُرصد IPv4 فقط في الإصدار الحالي.
- القائمة المضمّنة صغيرة. استبدلها بقائمة أكبر لتغطية أفضل.
- صلاحية `QUERY_ALL_PACKAGES` مطلوبة لعرض أسماء التطبيقات. لو نشرته على Google Play فسيحتاج تبريرًا.
- الخريطة تحمّل d3 وبيانات العالم من CDN. للعمل دون إنترنت ضع هذه الملفات في `assets/`.

## هيكل الملفات

| الملف | وظيفته |
|---|---|
| `KhaytVpnService.kt` | النفق، التقاط DNS، الحجب، التسجيل |
| `Dns.kt` | تحليل حزم DNS وبناء حزم IP/UDP |
| `Data.kt` | الأحداث، قائمة المتتبّعات، قائمة الحجب، GeoLite2 |
| `OverlayWindow.kt` | النافذة العائمة وجسر JavaScript |
| `MainActivity.kt` | الأذونات وزر التشغيل |
| `assets/map.html` | الخريطة والريبلاي وقطع الخطوط |
